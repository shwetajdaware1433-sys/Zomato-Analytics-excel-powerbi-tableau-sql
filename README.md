### Project Overview

The Zomato Analytics Dashboard is an interactive Tableau project designed to analyze restaurant data across multiple countries, cities, cuisines, and customer service features. The dashboard provides meaningful insights into restaurant trends, customer preferences, ratings, online delivery availability, and restaurant growth over the years.

The project focuses on transforming raw restaurant data into a visually appealing and business-oriented dashboard for better decision-making and analysis.

### Objectives
1. Analyze restaurant distribution across countries and cities.
2. Identify popular cuisines and customer preferences.
3. Understand restaurant rating patterns.
4. Compare online delivery and table booking availability.
5. Track restaurant openings over the years.
6. Build an interactive and user-friendly Tableau dashboard.

### Process
1. Data Collection
Imported the Zomato restaurant dataset into Tableau.
2. Data Cleaning
Removed unnecessary fields.
Handled missing/null values.
Corrected data formatting issues.
Standardized categorical values.
3. Data Preparation
Created calculated fields for KPIs and percentage analysis.
Organized dimensions and measures for visualization.
4. Dashboard Development
Built interactive charts and KPI cards.
Added filters for dynamic analysis.
Designed a clean and structured dashboard layout.

### Insights Generation
1. Most restaurants are rated in the “Good” category.
2. North Indian cuisine is among the most popular cuisines.
3. Online delivery services are more commonly available than table booking services.
4. Restaurant growth increased significantly after 2010.
5. Major restaurant concentration is observed in metropolitan cities.

### Challenges and Solutions

1. Missing or Incomplete Data
  Solution: Handled missing values by cleaning the dataset, removing incomplete          records, and standardizing important fields before visualization.
2. Inconsistent Data Formats
  Solution: Standardized data formats such as dates, ratings, and categorical values     to ensure consistency across the dashboard.
3. Dashboard Layout and Spacing Issues
   Solution: Improved alignment, spacing, and container organization to create a          cleaner and more professional dashboard design.
4. Managing Multiple Filters
   Solution: Organized filters in a dedicated section to maintain dashboard               readability and improve user interaction.
5. Representing Percentage-Based Metrics
   Solution: Used simplified bar charts and KPI indicators to present percentage          metrics in a more readable and visually effective way.
6. Maintaining Visual Consistency
   Solution: Applied a consistent color palette, font style, and chart formatting         throughout the dashboard for a professional appearance.
